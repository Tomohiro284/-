3ステップで変換する

このサイトは、入力した単語や文章を辞書にもとづいて対義語に置き換えるツールです。 会員登録もインストールも必要ありません。変換ツールを開いて、次の順に操作します。

  1. 原文を入力する — 単語だけでも、複数行の文章でも構いません。入力しながらリアルタイムに変換されます。
  2. そのまま残す語句を選ぶ — 変換される語がチップで一覧表示されます。クリックすると「そのまま」に切り替わります。
  3. 結果をコピーする — 変換した語は紫、そのまま残した語は緑で色分けされます。ボタンひとつでコピーできます。
例）今日はとても暑いので、大きい氷をたくさん買いました。
→ 今日は全然寒いので、小さい氷を少し売りました。

変換したくない語句を守る

固有名詞や決まった言い回しなど、変換されたくない語句は3つの方法で守れます。

1. 候補チップをクリックする
入力文から自動で見つかった語をひとつずつ切り替えます。「すべてそのままにする」「すべて変換する」で一括切り替えもできます。
2. 自分で語句を登録する
単語だけでなく文章まるごとも登録できます。たとえば「好きな食べ物は大きいケーキです」を登録すると、その一文だけ変換されません。
3. 自動除外にまかせる
URL・メールアドレス・`コード`・#タグ・@ユーザー名は、既定で変換されません。設定でオフにもできます。

登録した語句と入力文はブラウザ内（localStorage）に保存されるので、次に開いたときもそのまま使えます。

どこまで変換できるのか

形態素解析は使わず、約470組の対義語ペアを長い語から順に当てていく方式です。 辞書には終止形だけを登録し、活用形は自動で展開しています。

種類例
イ形容詞大きい → 小さい / 大きく → 小さく / 大きかった → 小さかった
動詞（五段・一段）買いました → 売りました / 笑った → 泣いた / 行きます → 来ます
名詞・形容動詞成功 → 失敗 / 静か → 賑やか / 過去 → 未来
英語big → small / stopped → started / Happy → Sad

変換元と変換先で活用の種類が違っても対応します（「増える」＝一段 → 「減る」＝五段 など）。 収録している対義語は変換ツールのページ下部「収録している対義語を見る」から検索できます。

誤変換を減らすしくみ

単純な文字列置換だと熟語の一部まで置き換わってしまうため、次のような判定を入れています。

  • 一文字の漢字（上・前 など）は、前後が漢字なら変換しない。
    → 上手 上野 はそのまま、上を見る は 下を見る に。
  • 二文字以下の仮名（はい など）は、後ろに平仮名が続くなら語の途中とみなす。
    → 今日はいい天気 を 今日は悪い天気 に（「はい」を拾わない）。
  • 保護した範囲に少しでも重なる語は変換しない。

それでも文脈によっては不自然な結果になります。うまくいかない語は、手順②で「そのまま」に切り替えてお使いください。

よくある質問

入力した文章はどこかに送信されますか？
いいえ。変換はすべてブラウザの中で完結します。サーバーには送信していません。
スマートフォンでも使えますか？
使えます。画面幅に合わせてレイアウトが変わります。
収録されていない対義語があります。
お問い合わせから教えていただければ、辞書への追加を検討します。
商用利用はできますか？
変換した文章の利用に制限は設けていません。詳しくは利用規約をご確認ください。
